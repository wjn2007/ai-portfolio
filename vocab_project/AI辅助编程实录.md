### 作业 1：精读 Python 官方教程（列表 / 字典 / 文件读写），补记第 4 条修改点

我精读了 Python 官方教程（中文）的「列表、字典、文件读写」三节，把**列表推导式**这一个写法正式用到了 `vocab_tool.py` 里：

```python
# 原来 AI 给的是 for + append 的循环写法：
def pick_level(words, level):
    picked = []
    for w in words:
        if w["HSK等级"].strip() == str(level):
            picked.append(w)
    return picked

# 我改成列表推导式（list comprehension），一行写完：
def pick_level(wordbook, level):
    return [w for w in wordbook if w["HSK等级"].strip() == str(level)]
```

**为什么改**：列表推导式比 for+append 更短、更 Pythonic，读起来也更像"筛选"这个动作；老师课件里也明确标了 `# 筛 列表推导式 一行顶三行`。同样的写法我也用在 `tally_pos` 里：`Counter(w["词性"].strip() for w in target_words)`。
